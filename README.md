# pfSense Firewall and Suricata IDS Lab

## Project Overview

This project demonstrates the implementation of a virtual cybersecurity lab using pfSense Firewall, Suricata IDS, Kali Linux, Ubuntu, Wireshark, and Nmap inside Oracle VirtualBox.

## Tools Used

* pfSense
* Suricata IDS/IPS
* Kali Linux
* Ubuntu
* Wireshark
* Nmap
* Oracle VirtualBox

## Objectives

* Configure pfSense firewall
* Create firewall rules
* Perform Nmap reconnaissance scans
* Analyze packets using Wireshark
* Install and configure Suricata IDS
* Monitor suspicious traffic

## Lab Architecture

* Kali Linux → Attacker Machine
* Ubuntu → Monitoring/Client Machine
* pfSense → Firewall + IDS

## Key Features

* TCP SYN Scan Detection
* Firewall Packet Filtering
* IDS Rule Configuration
* Network Traffic Analysis
* Virtual Internal Networking

## Outcome

Successfully built and tested a cybersecurity lab capable of monitoring and filtering reconnaissance traffic.
